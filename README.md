<h1>
  Inventory Management System (IMS)
</h1>
This app is taught from the Django training course on the net Ninja YouTube channel.
<br><br>
This app is built to manage the user's product inventory, which has the ability to manage all the products in the app. The most important feature of this app is that it has the ability to add, view, update, and delete any product.
<br><hr>
To use this program, download or clone the pipenv, crispy forms, and crispy bootstrap 5ra packages in Python:
<br>
1. To use it, you first need to install it in pip using the <code>pip install pipenv</code> command.
<br>
2. Run the <code>shell pipenv</code> command.
<br><br>
After that, you can empty or delete the db.sqlite3 file and create a file with the same name.
<br><br>
And then I run the following commands in the location where the manage.py file is located to create our raw database: 
<ul>
  <li>
    <code>
      Python3 manage.py makemigrate
    </code>
  </li>
  <li>
    <code>
      Python3 manage.py migrate
    </code>
  </li>
</ul>
<br><br>
This app is built with Django, Bootstrap 5, Crispy Forms, and Crispy Bootstrap 5.
